# Fonts

Drop these `.woff2` files here (download from JetBrains Mono GitHub releases):

- `JetBrainsMono-Regular.woff2`
- `JetBrainsMono-Bold.woff2`
- `JetBrainsMono-ExtraBold.woff2`

License: SIL Open Font License 1.1 — bundle with your deploy. Self-hosting is required for GDPR compliance (no Google Fonts CDN).

If files are missing, the site falls back to system monospace (defined in `styles/fonts.ts`).
